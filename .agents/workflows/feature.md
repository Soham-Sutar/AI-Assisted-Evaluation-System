# Feature Workflow

Description: Implement one coherent EvalAI feature without expanding scope.

## Steps
1. Read `AGENTS.md`.
2. Identify the single requested feature and its acceptance criteria.
3. Read only the relevant documentation files/sections.
4. Inspect existing code before creating new files or abstractions.
5. State a short implementation plan.
6. Implement only the requested feature and required dependencies.
7. Run focused tests/type checks/lint/build checks for affected areas.
8. Fix failures caused by the implementation.
9. Verify authentication, authorization, error handling, and data persistence when relevant.
10. Report changed files, verification results, and the next recommended task.

## Guardrails
- Do not implement the next roadmap task automatically.
- Do not refactor unrelated code.
- Do not fake AI, OCR, segmentation, assignments, evaluations, or results.
- Preserve original data and evaluation provenance.

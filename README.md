# EvalAI

AI-Based Modular Answer Sheet Evaluation System with Bias Detection

This repository is structured for agent-assisted development with Antigravity.

## Agent documentation

Start with `AGENTS.md`.

Use:
- `PROJECT_KNOWLEDGE.md` for product requirements, workflows, UI/UX, and AI behavior.
- `ARCHITECTURE.md` for technical architecture, database, APIs, modules, storage, and infrastructure.
- `DEVELOPMENT_RULES.md` for engineering, security, testing, logging, and performance rules.
- `TASK_PLAN.md` for roadmap and verification-oriented task planning.

## Antigravity customization

Workspace rules are in `.agents/rules/`.
Repeatable workflows are in `.agents/workflows/`.

Antigravity currently supports workspace rules in `.agents/rules`. Workflows are supported but are being migrated toward Agent Skills in current Antigravity documentation.

## Important

This repository is a development scaffold. `frontend/`, `backend/`, and `storage/` are intentionally empty until implementation begins.

Do not treat placeholder infrastructure files as a completed application.
